# Security Policy

## Supported Versions

EcoTracker Hub is currently under active development.  
Security updates are applied to the latest version of the project.

| Version | Supported |
| ------- | --------- |
| Latest  | Yes       |
| Older versions | No |

---

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly.

### How to report

- Open a **private security advisory** on GitHub (recommended), or  
- Contact the maintainer directly EcoAdmin@ecotrackerhub.eu

### What to include

Please provide as much detail as possible:

- Description of the vulnerability  
- Steps to reproduce the issue  
- Potential impact  
- Any suggested fixes (if available)

### Response process

- You can expect an initial response within a few days  
- Valid vulnerabilities will be investigated and addressed promptly  
- You will be informed about the outcome once the issue is reviewed  

### Responsible disclosure

Please do not publicly disclose the vulnerability until it has been reviewed and resolved.

---

## Scope

This policy applies to:

- The web application (frontend and backend)  
- Database interactions  
- Authentication and user data handling  

---

## Commitment

EcoTracker Hub is committed to maintaining the security and privacy of its users and continuously improving the platform.
